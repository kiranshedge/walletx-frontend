# WalletX UI Asset Pack

Brand direction: Simple. Secure. Yours.

## Included
- `logos/` — primary, horizontal, stacked, monochrome and app-icon SVGs
- `icons/` — reusable outline SVG icons for core MVP navigation/actions
- `backgrounds/` — lightweight SVG backgrounds/patterns
- `tokens/` — JSON design tokens and CSS variables
- `docs/` — implementation notes

## Core colors
Primary Violet: #6D28D9
Primary Dark: #4C1D95
Light Purple: #A78BFA
Ultra Light: #EDE9FE
Dark Text: #0F172A
Success: #16A34A
Danger: #DC2626

## Typography
Inter is the recommended typeface. Use 700 for major headings, 600 for section headings, and 400 for body text.

## Accessibility
Never communicate transaction direction through color alone. Use explicit `+` for money-in and `-` for money-out, with supporting labels such as "Money in" and "Money out".

## MVP scope
Login, Register, Dashboard, Add Money, Transfer Money, Transfer Confirmation, Transaction Activity.
No cards, investments, PIX, analytics, notifications, KYC or bank integrations.
